# RE:INVENT LAB
中学校のmicro:bit再発明プロジェクト用・制作マニュアルLPのモックアップ。

## ローカルで確認

```sh
cd /workspace/reinvent-manual
python3 -m http.server 8000 --bind 0.0.0.0
```

ビルド・パッケージのインストール不要。GitHub Pagesでルートを公開できます。

## 内容
- 6つの制作ステップ（クリックして詳細表示）
- 困ったときの確認手順と3つのGemの紹介
- 評価の到達イメージ（詳細評価表は調整中）
- 端末に保存される授業終了チェック
- レスポンシブ表示、キーボード操作、動きを減らす設定に対応

## 確認待ち
- デバイスガイドの機材・接続情報を制作手順に詳しく反映
- スライドテンプレート原本との対応
- 3つのGemのURL
- 価格ガイドと詳細評価表

Webページの直接取得には制限がありますが、Git経由でデバイスガイド原本を確認済みです。発表テンプレートの詳細は未確認です。

## 基準端末
11.6インチ・1366×768のタッチ対応Chromebookを主対象とします。
ブラウザ上部のUIを見込んだ1366×650のコンテンツ領域でも確認します。
主要操作は48px以上、手順本文は16px、カード本文は14px以上を基本とし、
ファーストビューに「やること・困ったとき・評価」の3つの入口を配置します。

## 追加した制作支援
- 明るさ／Teachable Machineの仕組みを切り替える入力・判断・出力の具体例
- 使用場面、反応、大きさ、電源を説明する製品図の比較
- 成功条件、条件変更、結果の分析と改良の手順
- 架空の実験記録例と動画撮影のポイント

Classの判定だけでなくmicro:bitの出力までを動作確認の対象にしています。
実験例の回数は評価条件ではありません。

製品図の「伝わる例」には、ChatGPT Imageで生成した引き出し警報装置の使用場面を使用しています。
生成イラストは完成イメージであり、実装済みの機能や正しい配線を保証するものではありません。

## 実物資料と説明イラスト
Microsoft MakeCode教材の実物写真から教室で使うmicro:bitのみを表示し、表裏とスピーカーを説明しています。出典とライセンスはassets/SOURCES.mdを参照。制作の6段階にはChatGPT Imageの作業イメージを掲載。配線・コードの正解を示す図とは区別しています。
